# A-cotton-weave

A front-end UI design practice project — a static landing page built to explore layout, typography, and visual styling using plain HTML and CSS.

## 🎯 About

This project was built as a design/UI exercise rather than a real product. The goal was to practice structuring a clean landing page: custom typography, image placement, and visual hierarchy — the fundamentals of front-end styling.

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — styling and layout
- Custom web font (`Pochaevsk-Regular.ttf`)

## ✨ Features

- Custom typography using a self-hosted font
- Clean, responsive layout
- Image-driven visual design

## 🚀 Getting Started

To view this project locally:

```bash
git clone https://github.com/shivamsingh-net/A-cotton-weave.git
cd A-cotton-weave
```

Then simply open `index.html` in your browser — no build steps or dependencies required.

## 📁 Project Structure

```
A-cotton-weave/
├── index.html          # Main page markup
├── style.css           # Styling
├── Pochaevsk-Regular.ttf  # Custom font
└── pic.png             # Image asset
```
